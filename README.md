# Status Saver for WhatsApp

## Overview

**Status Saver for WhatsApp** is an Android application that allows users to easily save and manage WhatsApp statuses, including images and videos. The app features a user-friendly interface with a tabbed layout for seamless navigation between images, videos, and saved statuses.

## Features

- **Tabbed Navigation**: 
  - Three tabs for quick access to:
    - Images
    - Videos
    - Saved statuses

- **Grid View**: 
  - Display images and videos in a grid format for easy browsing.

- **Item Actions**: 
  - Each item in the grid comes with three buttons:
    - **Save**: Download the status to the device.
    - **Add to Favorites**: Mark the status as a favorite for quick access later.
    - **View**: Open a zoomable image viewer for images and a video player for videos.

- **Zoomable Image Viewer**: 
  - Allows users to zoom in on images for a closer look.

- **Video Player**: 
  - Play videos directly within the app.

## Installation

1. Open the project in Android Studio.
2. Build the project and run it on an Android device or emulator.

## Usage

1. Open the app to view the WhatsApp statuses.
2. Navigate through the tabs to access images and videos.
3. Click on any item to view, save, or add it to favorites.
